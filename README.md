# Projet Hackaton

Prototype responsive de communauté pour développeurs : Reels, publications, forums, quiz et profils. Construit avec React, Vite, TypeScript et Tailwind CSS.

Les interactions de démonstration (profil, préférences, notifications, conversations et quiz créés) sont stockées dans le navigateur. Aucun compte réel ni service backend n’est connecté.

## Commandes

- `npm install` : installer les dépendances
- `npm run dev` : lancer le serveur de développement
- `npm run build` : vérifier les types et générer la version de production
- `npm run preview` : prévisualiser la version de production

L’apparence et la langue (français/anglais) se règlent depuis **Réglages**.

Les textes de l’interface sont traduits ; les contenus de démonstration (publications, discussions et messages) restent dans leur langue d’origine, comme du contenu partagé par les membres. Les écrans des derniers lots suivent le brief produit, les maquettes Figma n’ayant pas pu être consultées avec le quota MCP disponible.
